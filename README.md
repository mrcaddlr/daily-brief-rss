# daily brief rss

> a tiny little home for the daily gaming & tech brief

this repository powers a simple RSS feed for the daily brief, so it can be followed from an RSS reader instead of having to hunt around for each update.

## what’s inside

- `feed.xml` — the RSS feed
- `index.html` — a small landing page for humans who wander in
- `.github/workflows/update-feed.yml` — the automation that keeps things updated

## the brief

the feed is organized into the same sections as the daily brief:

1. **game & tech news**
2. **steam sale / event**
3. **xodus**
4. **free games**
5. **linux apps**
6. **piracy scene**

news stories are kept substantial rather than being turned into a giant pile of tiny headlines. ongoing stories can stay in the feed while they’re still relevant, with meaningful updates replacing stale information.
